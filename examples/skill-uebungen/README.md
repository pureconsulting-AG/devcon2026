# Skill-Übungen (Vorlage)

Übungsprojekt mit je einer Aufgabe pro Beispiel-Skill aus `examples/skills/`.
Einrichten als eigenes Git-Projekt (kopiert auch die Skills nach `.lcc/skills/`):

```bash
examples/skill-uebungen/einrichten.sh ~/lcc-uebungen
cd ~/lcc-uebungen
```

Die Aufgaben stehen in [UEBUNGEN.md](UEBUNGEN.md).
